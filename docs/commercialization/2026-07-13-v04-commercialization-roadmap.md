日期：2026-07-13（V0.5 进展更新：2026-07-14）

## 一、产品定位

**「临期零食真实价值决策 Agent」**：帮价格敏感型消费者在临期零食平台（好食期、甜牛、
拼多多临期专区、淘宝临期店等）快速判断一单是否真的划算——不是标价便宜，而是
「克单价 × 口味 × 到期风险 × 信息可信度」加权后的真实价值。

差异化壁垒：
1. **个人价格记忆**（历史基线克单价）——用得越久越准，形成迁移成本；
2. **真实价值公式**（real_value_price_per_g，5 因子）——比比价插件只看总价/克单价更深一层；
3. **截图即录入**（OCR 双后端）——录入成本足够低才有留存。

## 二、商业模式：三层漏斗

| 层级 | 形态 | 价格 | 对应技术开关 |
|---|---|---|---|
| **免费本地版** | 开源自部署（Docker 一键） | ¥0 | 不配置 `SNACKVALUE_API_KEYS`，开放模式 |
| **Pro 托管版** | 云端托管 + 云 OCR + 多端同步 | ¥9.9/月 或 ¥68/年 | API Key + `SNACKVALUE_DAILY_QUOTA` 放量 |
| **API 按量** | 比价/提取 API 给三方（比价社群机器人、返利工具） | ¥0.01/次，阶梯价 | `api_usage` 表按 key×日×端点对账 |

免费层是获客与口碑（开源社区 + 省钱社群传播）；Pro 层卖「省心」（免部署、云 OCR
更准、数据不丢）；API 层卖「能力」（真实价值评分作为基础设施输出）。

### 免费层限流参考

- 匿名/免费 key：计量端点 20 次/天（`SNACKVALUE_DAILY_QUOTA=20`）——覆盖个人日常比价绰绰有余，挡住脚本滥用；
- Pro key：500 次/天；
- 超额返回 429 + 升级提示文案（已实现）。

## 三、北极星指标与看板

北极星：**周活跃比价用户数**（7 日内发起过 ≥1 次 /api/compare 的去重主体）。

`GET /api/stats` 已提供的经营指标：

| 指标 | 商业含义 |
|---|---|
| `total_evaluations` / `active_days` | 使用规模与粘性 |
| `evaluations_last_7_days` | 近期活跃（留存代理） |
| `discount_savings` | 「已帮你省下 ¥X」——付费转化的核心文案素材 |
| `estimated_savings_vs_avg` | 相对个人均价的省钱量——价格记忆的价值证明 |
| `min_price_per_g` | 历史最优战绩——分享传播素材 |

`api_usage` 表（key × 日 × 端点）即计费对账单，出账只需一条 SQL。

## 四、GTM（Go-to-Market）

1. **冷启动（0→1k）**：开源发布 + 省钱/临期零食社群（豆瓣抠组、小红书临期话题）投放
   「省钱报告」截图（stats 数据自动生成）；
2. **增长（1k→10k）**：Pro 托管内测邀请制；与临期零食测评博主合作，博主专属 API key
   生成带署名的比价卡片；
3. **变现验证**：Pro 转化率 ≥3%、API 有 ≥2 个稳定集成方即验证通过，再投入多用户账号体系。

## 六、合规与信任

- **免责声明**：本工具输出为「价值参考」而非食品安全结论；临期食品可食性以商品标注
  的保质期与商家资质为准。✅ V0.5 已在前端页脚显式声明；正式服务条款文本待商用发布时补充。
- **隐私**：免费本地版数据 100% 留在用户设备（SQLite 本地文件）；托管版需明示
  「购买记录仅用于个人基线计算，不出售、不共享」，并提供导出/删除接口（GDPR/个保法对齐）。
- **开源许可**：建议主仓库 MIT（最大化获客），托管版增值部分（多租户、支付、报告页）
  闭源私有仓库——licensing 决策需 owner 拍板，本文档不代做。
